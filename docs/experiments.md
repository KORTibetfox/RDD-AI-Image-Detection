# 원본 실행 기록과 한계

출처: 사용자가 제공한 `lg-detection.ipynb`의 저장된 출력. 실행 날짜·정확한 패키지 버전·GPU 모델은 확인할 수 없습니다. 다음 표의 수치는 재실행하지 않았으며 원본의 출력 정밀도를 유지했습니다.

| 실험 | n | 성공 | threshold | mean | min | max |
|---|---:|---:|---:|---:|---:|---:|
| 생성 이미지 탐지 | 20 | 20 | 0.0001 | -0.0009518 | -0.0020271 | -0.0002915 |
| Picsum Real 가정 판정 | 20 | 20 | 0.0001 | 0.0006523 | 0.0001336 | 0.0017832 |

## 생성 이미지 실험

SD v1.4, 20 inference steps, 7개 사진 묘사 프롬프트 중 Python `random.choice`로 선택했습니다. 파이프라인용 torch Generator의 seed는 42이지만 Python random과 탐지에 쓰는 글로벌 torch 난수는 고정하지 않았습니다. 생성 이미지와 판별기가 같은 SD v1.4 구성요소를 공유하므로 다른 생성기로의 일반화 근거는 아닙니다.

## Real 가정 이미지 실험

`https://picsum.photos/seed/{1007+i}/512`에서 i=0..19로 수집했습니다. 원본 출력의 실패 수는 0입니다. 공급자가 제공한 사진을 실사로 가정했으며 진위를 별도 검증하지 않았습니다. seed URL은 수집 의도를 표현하지만 미래에도 동일 바이트를 반환한다고 보장하지 않습니다. 원본 바이트, 체크섬과 개별 점수는 저장되어 있지 않아 AUROC를 사후 계산할 수 없습니다.

## 해석과 다음 검증

- 0.0001은 노트북에서 사용한 실험용 값이며, 독립 검증 세트에서 보정한 보편적 임계값이 아닙니다.
- 표본 수가 작고 생성/수집 방식이 제한적입니다. 결과를 대규모 벤치마크 성능이나 서비스 수준 정확도로 해석할 수 없습니다.
- 정리된 코드로 다양한 실제 카메라·생성 모델·JPEG 품질·해상도 조건을 평가하고 이미지별 점수와 환경을 남겨야 합니다.
- 임계값 보정용 검증 세트와 최종 평가 세트를 분리하고 AUROC, AI recall, Real false-positive rate를 함께 측정해야 합니다.
- 원본 설치 로그에는 Kaggle CUDA 관련 패키지 충돌 경고가 있어 해당 환경을 정상적인 고정 환경으로 재현했다고 주장하지 않습니다.
