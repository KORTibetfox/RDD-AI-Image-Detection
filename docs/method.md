# 구현 메모

## 수식의 출처와 구현 범위

참고 논문은 LG AI Research가 CVPR 2026 논문으로 소개한 [A Debiased Reconstruction-based Framework for Training-Free Detection of AI-Generated Images](https://www.lgresearch.ai/publication/view?seq=166)입니다. 공식 소개의 이미지/잠재 공간 편향 제거 설명과 원본 노트북의 RDD 분기 및 점수 조합이 대응합니다. 이전 대화에서 후보로 언급한 WaRPAD(크롭 강건성 기반 논문)는 이 노트북의 직접 참고 논문으로 기재하지 않았습니다.

정리본의 구체적 수식과 코드는 제공된 노트북에서 옮겼습니다. 논문 PDF 본문은 정리 시점의 접근 오류로 직접 열람하지 못했으므로, 모든 세부 구현이 논문과 일치한다고 주장하지 않습니다. [CVF 보충자료의 검색 가능 내용](https://openaccess.thecvf.com/content/CVPR2026/supplemental/Choi_A_Debiased_Reconstruction-based_CVPR_2026_supplemental.pdf)은 여러 확산 모델을 결합하는 평가 설정을 설명하며, 이 프로젝트는 SD v1.4 하나만 사용합니다.

## 노트북의 계산 흐름

1. RGB 변환 및 512×512 강제 리사이즈 후 [-1, 1]로 정규화합니다.
2. 원본, Gaussian blur(3×3, sigma=0.8), 90도 회전, 회전 후 blur의 VAE 복원 LPIPS 오차를 각각 구합니다.
3. 네 오차를 README의 `S_image` 식으로 조합합니다. 회전 가중치는 0.5입니다.
4. 별도로 샘플링한 VAE 잠재값에 VAE 설정의 scaling factor를 적용합니다.
5. DDPM 학습 타임스텝 수의 5% 지점에서 노이즈 예측 MSE를 16번 평균합니다. 빈 텍스트 임베딩으로 UNet을 조건화합니다.
6. 회전된 잠재값의 오차에서 원래 오차를 빼 `S_latent`를 구한 뒤, 제곱해 `S_image`와 곱합니다.

VAE posterior는 mode 대신 sample을 유지했습니다. 원본과 회전 잠재 분기의 노이즈도 독립적으로 뽑습니다. 재구성에 사용한 원본의 `latent * scale / scale`은 상쇄되므로 정리본에서 생략했습니다. 잠재 노이즈 예측 경로의 scaling은 유지했습니다.

## 정리하면서 바꾼 점

- 모델과 전처리를 클래스에 모으고, 중복 분류 함수를 제거했습니다.
- 빈 텍스트 임베딩을 한 번만 계산하고, 노이즈 16개를 기본적으로 하나씩 처리합니다. `--noise-batch-size 16`은 원본의 전체 배치 구조에 가깝지만 메모리를 더 씁니다.
- 추론별 전용 RNG를 seed 42로 초기화합니다. 원본은 생성 파이프라인에만 시드를 지정해 탐지 과정의 난수까지 고정하지 못했습니다.
- EXIF 방향을 보정하고, 잘못된 크기·샘플 수·임계값 및 비정상 점수를 검사합니다.
- 검증되지 않은 임계값을 자동 적용하지 않고 기본값은 점수 출력만 제공합니다.
- 생성 실험은 보존용 노트북에 남기고 로컬 CLI는 이미지 판독만 수행합니다.

이 변경은 사용성과 실행 반복성을 위한 것이며 새로 평가된 정확도 개선을 의미하지 않습니다. 리사이즈와 EXIF 보정, RNG 및 배치 변경 때문에 과거 출력과 일치하지 않을 수 있습니다. 단일 모델만으로 전체 논문의 성능을 재현했다고 볼 수 없습니다.
